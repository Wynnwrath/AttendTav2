# Member paged list with search and Tailwind shell

## Description

Applies 25-row server-side pagination with the shared pager to the Member management list, ordered by users.full_name with a member_id tie-break, with search by name or student number, styled in the Tailwind shell; membership status is displayed read-only.

## Requirements

Verify: An Officer searches members by name or student number on the Tailwind Member Index, navigates pages with Previous/Next using the 25-row pager, and sees membership status displayed read-only.
